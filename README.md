A travel poster for Thalvor, a city that does not exist: a cliffside town on a floating peak above a sea of clouds, joined by a single lantern-lit stone bridge to a small pine-topped rock, with a waterfall spilling off the island's edge and golden-hour sun warming the whole sky. The poster is rendered procedurally and deterministically with Python and Pillow — a fixed seed, layered gradients, soft cloud banks, and hand-placed type — so every run produces the byte-identical 1024x1024 PNG.

## Run it

```sh
python3 render.py && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
